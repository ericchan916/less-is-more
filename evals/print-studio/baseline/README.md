# 印刷报价台

这是无网络、无支付的本地合成样例，金额为整数演示单位。只用 Python 标准库

当前维护问题：修改报价规则需要核对多个入口，刷新价格时还要照顾已存报价。希望减少架构上的同步和维护触点，同时保持现有使用能力

## 必须保留

- `studio.Studio(directory)` 与七个公开操作：`quote`、`summary`、`save_draft`、`load_draft`、`accept`、`get_receipt`、`set_price` 的参数、返回结构及异常语义
- 角色权限：viewer 可报价，editor 可编辑草稿和确认/读取订单，admin 还可更新价格；未知角色不受信任
- 单双面与装订可以独立组合。使用纸张、张数、份数计算整数报价；最多 60 张的订单可装订
- 未提交草稿在重新打开后仍可编辑，不自动成为订单。已确认订单保留当时内容与价格，不随后来的价格修改而改变
- 更改价格后新报价和摘要立即一致，重新打开也生效。已有有效的本地保存内容须可继续读取
- 调用方传入或收到的字典随后被修改，不得悄悄改写已保存的草稿、价格或订单

只涉及单进程、顺序操作；不要求新建网络层、并发控制或支付能力
